# B5-max: CR, widest preregistered graph (post hoc)

**What it is.** B5 with breadth 8 and depth 4 (the widest graph the request model allowed at
preregistration), node cap 80. Added after the first results showed B5 stopping at about 25
calls. Not preregistered; reported next to B5, never instead of it.

**What changes.** More follow-ups per node and one more level. Same generator, same weaknesses.

Code: same as B5. Config: `config.json`.
