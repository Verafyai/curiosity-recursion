\section{Related work}
\label{sec:related}

\paragraph{Reasoning and acting agents.} ReAct interleaves reasoning traces and tool actions on one trajectory \citep{yao2023react}. Reflexion adds verbal self-feedback across attempts \citep{shinn2023reflexion}, and Self-Refine iterates on its own output \citep{madaan2023selfrefine}. Tree of Thoughts searches over intermediate reasoning states with a model as evaluator \citep{yao2023tot}. Self-Ask decomposes a question into follow-up sub-questions answered in turn \citep{press2023selfask}, and IRCoT interleaves retrieval with chain-of-thought steps \citep{trivedi2023ircot}. Toolformer teaches a model when to call tools \citep{schick2023toolformer}. Voyager keeps an automatic curriculum and a growing skill library, a form of persisted exploration \citep{wang2023voyager}. \Cref{sec:loop} contrasts CR with these methods.

\paragraph{Search over branches and agreement.} Language Agent Tree Search runs Monte Carlo tree search over agent trajectories, with a model-based value function and self-reflection, and reports 92.7\% pass@1 on HumanEval and an average score of 75.9 on WebShop \citep{zhou2024lats}. RAP also plans with Monte Carlo tree search, using the model as its own world model \citep{hao2023rap}. Both build on UCT, which picks the branch to expand with an upper confidence bound \citep{kocsis2006uct,auer2002ucb}. Self-consistency samples several reasoning paths and keeps the majority answer, adding 17.9 points on GSM8K \citep{wang2023selfconsistency}. Simple sampling and voting improves with the number of agents \citep{li2024moreagents}, and multiagent debate improves factual validity by having model instances critique each other over several rounds \citep{du2024debate}. CR's single-pass graph has no value estimate over its open questions; the v0.2 design scores every lead and expands the best first.

\paragraph{Deep research and web agents.} WebGPT answers questions by browsing with human feedback \citep{nakano2021webgpt}. STORM writes Wikipedia-like articles after generating questions from several simulated perspectives; editors rated 25\% more of its articles organized and 10\% more broad in coverage than an outline-driven retrieval baseline \citep{shao2024storm}, the closest prior use of question generation to drive coverage. Commercial \citep{openai2025deepresearch} and open-source \citep{elovic2023gptresearcher} deep-research agents run multi-step research in one session; none is built to wait weeks for a letter, survive a crash, or prove which sources it checked.

\paragraph{Multi-agent research systems.} Anthropic's research system uses an orchestrator that splits a question into subtasks for parallel subagents; on its internal research eval it beat a single agent by 90.2\%, and on BrowseComp token usage alone explained 80\% of the performance variance, at about 15 times the tokens of a chat \citep{anthropic2025multiagent}. The same post reports that vague task descriptions made subagents duplicate each other's work. Co-STORM lets several agents converse while a shared mind map tracks what has been found \citep{jiang2024costorm}, and AutoGen is a general framework for such conversations \citep{wu2023autogen}. A study of 1600+ traces from seven multi-agent frameworks finds that gains over single agents are often small and names 14 failure modes, including weak task verification \citep{cemri2025mast}. Recent deep-research agents interleave reasoning with search \citep{li2025searcho1,li2025webthinker}, train the search policy with reinforcement learning on the live web \citep{zheng2025deepresearcher}, and are surveyed in \citet{huang2025drsurvey}. Because spend explains so much of the variance, we compare such systems with CR only at a matched tool-call budget.

\paragraph{Query reformulation and repeated search.} Rewrite-Retrieve-Read rewrites the query before retrieval \citep{ma2023rewrite}; Query2doc expands it with a model-written pseudo-document, improving BM25 by 3\% to 15\% \citep{wang2023query2doc}; HyDE retrieves with a hypothetical document's embedding \citep{gao2022hyde}; and FLARE decides when and what to retrieve during generation \citep{jiang2023flare}. Tabu search keeps a list of recent moves that may not be repeated unless an aspiration rule allows it \citep{glover1997tabu}, which is the shape of the search ledger planned for CR v0.2. Name variation and blocking for genealogy follow the record-linkage literature \citep{christen2012datamatching}. In v0.1.0, \RESULT{diag-repeat-B5} of B5's tool calls repeated an earlier call exactly (\cref{sec:corpus}), so this line of work applies directly.

\paragraph{Agent benchmarks.} WebArena \citep{zhou2024webarena}, GAIA \citep{mialon2024gaia}, BrowseComp \citep{wei2025browsecomp}, SWE-bench \citep{jimenez2024swebench} and DeepResearch Bench \citep{du2025deepresearchbench} measure agents on web tasks, hard-to-find facts, code and research reports. To our knowledge, none scores hidden archival records by how dark they are, counts a correctly drafted request to an offline archive as a find, or injects crashes and multi-day waits.

\paragraph{Curiosity, novelty and active questioning.} Intrinsic-motivation work rewards an agent for what it cannot yet predict \citep{pathak2017curiosity,schmidhuber2010creativity}. Novelty search abandons the objective and rewards behaviour that differs from what came before \citep{lehman2011novelty}. Active learning chooses the queries whose answers are most informative \citep{settles2009active}, and neural question generation learns to ask questions about a text \citep{du2017learning}. Go-Explore remembers the states it has visited, returns to a promising one and explores from there \citep{ecoffet2021goexplore}, and information foraging theory models a searcher who leaves a patch when its rate of gain falls below what other patches promise \citep{pirolli1999foraging}. Reflexion keeps those lessons in an episodic memory between attempts \citep{shinn2023reflexion}, as generative agents do with periodic reflections \citep{park2023generative}. CR borrows the reward for novelty, but applies it to a space of questions whose payoff is external and checkable: a record exists or it does not.

\paragraph{Record linkage and genealogy data.} Probabilistic record linkage \citep{fellegi1969linkage} and its large-scale historical uses \citep{abramitzky2021linking,price2021censustree} decide when two records describe one person. CR treats a name match as a lead and leaves identity to evidence and review (\cref{sec:wrongparents}).

\paragraph{Archives and dark data.} Dark data and handwriting recognition are discussed in \cref{sec:darkdata}; the FAIR principles describe what findable data needs \citep{wilkinson2016fair}, and we document the benchmark with a datasheet \citep{gebru2021datasheets}.

\paragraph{Durable execution.} Sagas split a long-lived transaction into steps with compensations \citep{garciamolina1987sagas}. Durable Functions give stateful serverless code replay semantics \citep{burckhardt2021durable}. Temporal records every workflow step in an event history and replays deterministic workflow code to recover state \citep{temporaldocs,temporalpythonsdk}. We use it because the research loop is a long-lived process with external side effects, timers measured in weeks, and a human in the loop.
