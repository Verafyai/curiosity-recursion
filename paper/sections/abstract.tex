\begin{center}\begin{minipage}{0.86\textwidth}\small\textbf{Abstract.} Research agents stop early. A person who used an AI assistant to research 65 of his own relatives found that the real work was supervision: typing ``go deeper'', ``are you sure?'', ``did you check the churches?'' and ``did that archive ever reply?'' again and again. Genealogical records make this worse, because many of them are dark data: scanned but unindexed, held by small archives that answer letters weeks later, behind logins, or kept in family boxes. We present \emph{\CR} (CR), a procedure that turns the human nudging loop into an explicit question graph. Every new question must be grounded in a quoted finding, is deduplicated against a persisted memory of every question asked before, and is expanded under breadth, depth, node, budget and time limits with explicit stopping rules. We run CR as a durable workflow on Temporal, so a run survives worker crashes, retries flaky archives, waits days on durable timers, and pauses for a human to approve or redirect it, with the full event history as an audit trail. We also define \emph{\bench}, a benchmark of hidden records about deceased people, stratified by darkness tier, with fault injection and adjudicated scoring; version 0 has 39 subjects and 671 hidden records. A pilot shows the loop surviving repeated worker kills without repeating finished lookups, and an error analysis shows how a quoted-evidence conflict check caught a wrong-parents lead. We report two evaluations, both measured. On the preregistered record-level comparison (\RESULT{n-subjects-test} test subjects, 100 tool calls each), CR found \RESULT{H1-recall-B5-B100} of the hidden records, against \RESULT{H1-recall-B1-B100} for a ReAct agent and \RESULT{H1-recall-B0-B100} for single-pass search: the main hypothesis is not supported. On a corpus-replication benchmark that asks each strategy to rebuild six hand-built family dossiers from a name and birth year alone, with the author's own sites blocked, CR recovered \RESULT{corpus-overall-B5} against \RESULT{corpus-overall-B1} for ReAct and \RESULT{corpus-overall-B0} for single pass, with the highest precision of any strategy (\RESULT{corpus-prec-B5}); a post hoc repair of its question rules reached \RESULT{corpus-overall-B5fix}. None of these differences is significant with six people. The tools could reach only part of each dossier, none of one veteran's facts, and that ceiling limited every strategy more than the choice of strategy did. A preregistered v0.2 (\cref{sec:swarm}) runs parallel lanes as Temporal child workflows behind a shared search ledger that refuses repeat calls; it cut exact repeats to \RESULT{v02-waste-repeat} and used \RESULT{v02-waste-used} of the budget at zero model spend, and its precision (\RESULT{v02-prec-B6-swarm}) was above both comparators, but it recovered \RESULT{v02-overall-B6-swarm} against \RESULT{v02-overall-B1} for ReAct and \RESULT{v02-overall-B5-fix} for the best v0.1 rules: the main v0.2 hypothesis is not supported. Durability held: under injected faults and worker kills both the durable and the plain loop finished every run, but only the plain loop lost and redid finished work. Paper version \paperversion.
